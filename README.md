# MiniAuth

Учебная авторизация на двух процессах. Страница шлёт регистрацию и вход на Express. Сервер хранит пользователей в `users.json`, пароль пишет хешем, на вход отдаёт JWT. Клиент кладёт токен в `localStorage` и ходит с ним на `GET /me`.

## Что умеет

- Регистрация: логин, почта, пароль. Пароль короче 6 символов не принимается
- Вход по почте и паролю. Ответ: токен и пользователь без хеша
- `GET /me` с заголовком `Authorization: Bearer <token>`
- `GET /health` — сервер жив
- На старте страница спрашивает `/me` и показывает «привет, логин» или остаётся гостем
- Выход снимает токен на клиенте и прячет кнопку

## Требования

- Node.js
- npm

Фронт открывается отдельно на `http://127.0.0.1:5500`. Сервер слушает `http://127.0.0.1:3000`. Адрес зашит в `api.js`. CORS на сервере разрешает только этот origin.

## Установка

Из папки сервера:

```bash
npm install
```

Нужны `express`, `cors`, `bcrypt`, `jsonwebtoken`. Они должны быть в `package.json`.

## Запуск

```bash
node server.js
```

Рядом с `server.js` должен лежать `users.json`. Это массив. Пустой старт — `[]`. Фронт — своим статическим сервером на порту 5500.

Проверка: `http://127.0.0.1:3000/health` отвечает `{ "ok": true }`.

## Двери

`POST /register`

```json
{ "login": "max", "email": "max@mail.com", "password": "secret" }
```

201 и пользователь без `passwordHash`. 400, если поле пустое или пароль короткий. 409, если почта или логин уже есть.

`POST /login`

```json
{ "email": "max@mail.com", "password": "secret" }
```

200 и тело `{ "token", "user" }`. 401, если почты нет или пароль не сошёлся. Токен живёт 2 часа.

`GET /me`

Заголовок: `Authorization: Bearer <token>`. 200 и `{ "user" }`. 401, если токена нет, он битый или пользователя уже нет в файле.

Клиент пишет токен в `localStorage` под ключом `authToken`.

## Структура

```
server/server.js       Express, bcrypt, jwt
server/users.json      пользователи, пароль только хешем
front/index.html       две формы, #out, кнопка выхода
front/script/js/api.js запросы
front/script/js/main.js экран
front/style/css/main.css
```

Имена папок на диске могут отличаться.

## Ограничения

- Секрет JWT зашит в `server.js`. 
- `127.0.0.1` с телефона и с чужого компьютера не работает.
- Репозиторий на GitHub сервер не запускает.
